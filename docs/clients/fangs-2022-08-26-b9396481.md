## How it runs on our stack

- **Custom lobbies:** the client creates and lists lobbies at a hard-coded Zeuz URL
  (`session-manager.ims.improbable.io/api/v0/projects/<ZeuzIMSProject>/sessions`). FangsBoot sets
  `UseLAN` so those calls are skipped, and does them itself against the backend (`POST /zeuz/sessions`,
  `GET /zeuz/sessions.txt`) from post-hooks on `WB_PlayMenu_C` (`CreateLobbyAndJoin`, `FindLobbies`).
- **PLAY (Casual):** same AccelByte matchmaker WebSocket as Feb 2023. The client asks for hero select
  only once, on joining (while the lobby still has 8 slots), so FangsHost starts it when everyone is in.
- **Augments:** only those in the season data's `AvailableAugments` are offered
  (`backend/seed/augments-alpha7.json`, see `docs/recon/backend-api.md`).
- Lambda routes come without a separator (`/fangsapivivox-token`); the backend accepts both forms.
  `get-epoc` must return `{"timestamp": <int>}`.
- The Aug hero button only calls `WB_MainMenuRef:UpdatePlayerHero` (no `UpdateChosenHero` yet).
