## Build facts / differences from the playtest (`main_v0_0_444`)

- **Shipping** configuration: `MOBA/Binaries/Win64/MOBA-Win64-Shipping.exe` (88 MB). No console,
  essentially **no log file**, no source paths. PDB not shipped.
- Same engine (UE 4.26.2 `++UE4+Release-4.26-CL-0`), same AccelByte SDK (16.1.0), same game
  instance / lobby / game-mode classes, same hero set and maps (+ `LE_UnderWorldArena`).
- `Saved/` (config, saves) lives in **`%LOCALAPPDATA%\MOBA\Saved`**, not the game folder.
- Live backend was `accounts.playfangs.com`; lambda API environment segment `/prod/` (playtest: `/dev/`).
- The pak (**46,370 files**) is **AES-256 encrypted** (index + every file). The key is embedded in
  the exe; `tools/pak/findkey_code.py` recovers it from your own copy. Keys are never committed —
  pass them to `tools/pak/*` as `@work/re/<file>`.
- UE4SS finds `ProcessLocalScriptFunction` natively (no custom signature needed, unlike the playtest).
- Server-side CloudSave calls are compiled-out stubs here as well → FangsHost shim required.
