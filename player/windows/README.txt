Fangs: Community Edition - player package
==========================================

Unofficial, non-commercial fan project to keep FANGS playable. Not affiliated with,
endorsed by or sponsored by Hidden Leaf Games or any owner of FANGS. We do not own FANGS
and cannot grant any rights to it. This package contains no game files.
Project page: https://github.com/anomieko/fangs-community-edition

Server: @SERVER@
Game build: @BUILD@

Install
-------
1. You need FANGS installed (game build: see above).
2. Extract this zip INTO your FANGS game folder (the folder that contains "MOBA").
   Allow it to merge folders.
3. Double-click FangsCE.bat. The first time it asks for a player name.

Play
----
- Main menu -> Play -> Custom: create a lobby, or join one from the list.
- The lobby owner presses Start once everyone has picked a hero.

Uninstall
---------
Delete FangsCE.bat, the FangsCE folder, MOBA\Binaries\Win64\dwmapi.dll,
MOBA\Binaries\Win64\ue4ss, MOBA\Saved\Config\WindowsNoEditor\Engine.ini and
%LOCALAPPDATA%\MOBA\Saved\Config\WindowsNoEditor\Engine.ini.

Includes UE4SS (https://github.com/UE4SS-RE/RE-UE4SS, MIT License; see
MOBA\Binaries\Win64\ue4ss\LICENSE).
